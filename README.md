# geo-select

Interactive world map based region selector. 국가나 지역을 지도에서 클릭하거나 검색해 선택하면 ISO 코드, 이름, 중심 좌표 등 애플리케이션에서 바로 사용할 수 있는 값을 반환합니다.

## 왜 geo-select인가

글로벌 SaaS의 회원가입, 온보딩, 청구지 입력에서는 사용자가 긴 국가 목록을 셀렉트 박스에서 찾아야 하는 경우가 많습니다. 국가는 위치로 기억하는 경우가 많은데도 텍스트 목록만 제공하면 탐색이 느리고, 비슷한 이름이나 언어 차이 때문에 실수하기도 쉽습니다.

geo-select의 목적은 단순히 세계 지도를 그리는 것이 아닙니다. 지도, 검색, 목록, 키보드 조작을 하나의 선택 상태로 연결해 사용자가 익숙한 방식으로 국가나 지역을 빠르게 찾고, 서비스는 안정적인 ISO 기반 값을 폼에 제출할 수 있게 하는 것입니다.

> **North Star:** geo-select는 장식용 지도 라이브러리가 아니라, 지도라는 상호작용을 더한 프로덕션용 국가·지역 폼 컨트롤입니다.

## 제품 원칙

1. **폼이 먼저다.** 지도는 선택을 돕는 인터페이스이며, `name`, `value`, `required`, `disabled`, 유효성 검사, 초기화, `input`/`change` 같은 표준 폼 동작과 자연스럽게 연결되어야 합니다.
2. **지도만 강요하지 않는다.** 검색과 접근 가능한 목록은 지도와 같은 결과를 제공해야 합니다. 작은 섬나라, 키보드 사용자, 스크린 리더 사용자, 좁은 모바일 화면에서도 선택할 수 있어야 합니다.
3. **사람에게는 익숙한 이름, 시스템에는 안정적인 코드.** 표시 이름은 로케일에 맞출 수 있어야 하고, 제출값은 ISO 3166 기반 코드와 명확한 국가·행정구역 구분을 사용해야 합니다.
4. **사용자의 선택을 존중한다.** IP나 브라우저 로케일로 후보를 제안할 수는 있지만 명시적인 동의 없이 국가를 확정하지 않습니다.
5. **가입·주소·결제 흐름에 쉽게 삽입된다.** 특정 프레임워크나 결제 사업자에 종속되지 않고 기존 폼 및 결제 UI와 조합할 수 있어야 합니다. geo-select는 카드 번호 같은 결제 정보 자체를 수집하거나 결제 규정 준수를 대신하지 않습니다.
6. **필요한 데이터만 비용을 지불한다.** 코어는 작고 프레임워크 독립적으로 유지하며, 세계 경계 데이터와 세부 행정구역 데이터는 선택적으로 지연 로드할 수 있어야 합니다.

## 현재 방향 점검

현재 구현은 이 목적을 향해 올바르게 가고 있습니다.

- 실제 국가·영토 경계와 ISO 코드, 이름, 중심 좌표를 제공
- 지도 클릭, 검색 하이라이트, 선택 상태, 대륙 필터를 코어 API에서 동기화
- 키보드 선택과 기본 SVG 접근성 제공
- `bindFormField()`로 ISO 국가값을 실제 HTML 폼의 입력값과 검증 상태에 연결
- `loadSubdivisions()`로 선택 국가의 ISO 3166-2 1차 행정구역 데이터를 선택적으로 연결
- 로케일별 이름, 별칭, 발음 구별 기호 무시 검색, RTL 방향을 지원
- 반응형 지도, 작은 지역 터치 대상, 허용·제외 국가 및 행정구역 정책을 지원
- 포인터 위치 중심의 마우스 휠 확대·축소와 확대 후 드래그 이동을 지원
- 불러온 행정구역을 키보드 접근 가능한 별도 지도 레이어로 렌더링하고 국가 지도와 자동 전환
- 원격 GeoJSON 로딩 상태, 오류 알림, 명시적 재시도를 지원
- 프레임워크 독립적인 코어와 선택적으로 불러오는 세계 데이터 제공

아직 완성된 SaaS 폼 컨트롤로 가기 위해 다음 작업이 남아 있습니다.

1. 모바일 팝오버/모달, 데이터 지연 로딩과 번들 크기 최적화
2. 국가와 행정구역 사이의 모바일 탐색 흐름 및 더 풍부한 선택 UI
3. 프레임워크 래퍼와 결제·가입 폼 통합 예제

예약 유지보수 작업은 위 순서를 제품 우선순위로 삼고, 매번 실제 가입 또는 청구지 입력 시나리오에서 사용자가 체감할 수 있는 한 가지 개선을 완성합니다.

https://muganghskim.github.io/geo-select/

## 설치

```bash
npm i geo-select-core
```

레포에서 직접 테스트하려면:

```bash
git clone https://github.com/muganghskim/geo-select.git
cd geo-select/packages/core
npm install
npm run build
```

자세한 API와 데이터 사용법은 [`packages/core/README.md`](packages/core/README.md)를 참고하세요.
