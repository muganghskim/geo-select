# World data license

The bundled 1:50m country boundaries and country metadata are derived from
[Natural Earth](https://www.naturalearthdata.com/).

Natural Earth raster and vector map data are in the public domain. The source
country layer is `ne_50m_admin_0_countries`; capital names and coordinates are
from `ne_110m_populated_places_simple`.

Source repository: https://github.com/nvkelso/natural-earth-vector

Terms of use: https://www.naturalearthdata.com/about/terms-of-use/
